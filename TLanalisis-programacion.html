Modalidad

Presencial, A distancia y Virtual

Tipo de programa

Técnico Laboral

Duración

640 horas

Certificación

Técnico Laboral en Análisis y Programación de Sistemas

Área de formación

Ciencias naturales, aplicadas y relacionadas (Código CUOC: 35121)

¿A quién va dirigido?

Estudiantes, emprendedores, entusiastas de la tecnología y profesionales de diversas ramas que deseen adquirir competencias sólidas en la creación de software, análisis de sistemas y administración de bases de datos para el sector público y privado.

Perfil del egresado

  • Diseñar y estructurar arquitecturas lógicas para aplicaciones comerciales.
  • Codificar y dar soporte a plataformas de software web frontend y backend.
  • Implementar, migrar y administrar bases de datos relacionales y no relacionales de manera segura.
  • Automatizar procesos organizacionales mediante código limpio y eficiente.
  • Aplicar metodologías ágiles de desarrollo para el trabajo eficaz en equipos tecnológicos.

Competencias que desarrollarás

  • Dominio de lógica de programación y algoritmos computacionales.
  • Desarrollo de interfaces de usuario modernas, interactivas y responsivas.
  • Creación de arquitecturas de servidores y consumo de API REST de forma óptima.
  • Gestión, seguridad y modelado de datos corporativos.
  • Pruebas de software, control de versiones (Git) y despliegue en entornos web.

Plan de estudios

  • Lógica de Programación y Estructuras de Datos (90 horas)
  • Modelado y Administración de Bases de Datos (100 horas)
  • Desarrollo Web Frontend (HTML, CSS, JavaScript) (120 horas)
  • Desarrollo Backend y Arquitectura de Servidores (120 horas)
  • Análisis de Requerimientos y Metodologías Ágiles (90 horas)
  • Seguridad Informática y Despliegue de Aplicaciones (80 horas)
  • Proyecto Final Integrador (40 horas)

Duración total: 640 horas

Requisitos de ingreso

  • Básica secundaria aprobada
  • Acceso a un computador y conectividad a internet
  • Cumplir con las condiciones metodológicas institucionales

Metodología de formación

Formación teórico-práctica centrada en proyectos del mundo real. El estudiante aprenderá mediante la resolución de problemas lógicos, el diseño directo de interfaces y la creación de un portafolio de software propio guiado por tutores expertos.

Sistema de evaluación

  • Entregas periódicas de retos de programación por módulo
  • Pruebas prácticas de despliegue y desarrollo técnico
  • Sustentación del Proyecto Final Integrador

Para aprobar, el estudiante debe cumplir mínimo con el 80 % de las actividades evaluativas y demostrar suficiencia práctica en los proyectos autónomos.

Campo de desempeño

  • Desarrollador Full Stack Jr. en empresas de software o tecnología
  • Analista o arquitecto técnico de sistemas de información corporativos
  • Administrador junior de bases de datos e infraestructura digital
  • Programador autónomo / Freelancer enfocado en desarrollo de plataformas SaaS
  • Soporte técnico especializado en mantenimiento y actualización de aplicaciones
